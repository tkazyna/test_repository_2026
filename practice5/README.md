# Practice5: Receipt Parser

This project is a Python practice exercise for parsing receipts using Regular Expressions.

## Files

- `receipt_parser.py` - main Python script that extracts products, prices, total, date, time, and payment method.
- `raw.txt` - sample receipt text file.
- `regex.py` - Python RegEx exercises.

## Features

- Extract all products from the receipt
- Extract prices of each product
- Calculate total amount
- Extract date and time
- Find payment method
- Output data in JSON and tabular format

## Usage

Run the parser with:

```bash
python3 receipt_parser.py
